# ⭐ Featured Projects

## 🔍 DPI Engine
### Real-Time Network Traffic Analyzer

**Java 21 • Spring Boot • Angular • WebSocket • Redis • Docker**

A real-time network traffic analyzer designed to identify applications from encrypted network traffic using TLS/SNI information.

### Highlights

- 🚀 Classified **18+ applications**
- ⚡ Java virtual threads for traffic processing
- 🔐 Byte-level TLS/SNI parsing using `ByteBuffer`
- 📊 Live packet/sec dashboard
- 🔄 WebSocket-based real-time updates
- 🧱 Firewall rule manager
- ⚡ Redis rule caching
- 🔒 Lock-free hot reload using `AtomicReference`
- 🐳 Dockerized application

## 🍎 NutriVision
### Food Calorie Estimation Using Computer Vision

**Python • Flask • React-Vite • YOLOv4 • OpenCV • SQLite • JWT**

A computer vision application that detects food from an image and estimates portion size, mass and calorie values.

### Highlights

- 🧠 Custom YOLOv4 model
- 📈 **98.6% mAP**
- 📷 Single-image food detection
- 📏 Pixel-based portion calibration
- 🔥 Calorie estimation
- 🔐 JWT authentication
- ⚡ Flask REST APIs
- 💻 React-Vite frontend
- 🗄️ Persistent scan history
